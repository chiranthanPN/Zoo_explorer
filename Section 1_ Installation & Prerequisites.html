Section 1: Installation & Prerequisites

1.1 Overview

Before we begin building Django applications, we must set up a development environment that supports Python, Django, and the supporting libraries required for a full-stack workflow.
This section covers:
System prerequisites
Installation of Python and Django
Setting up a Virtual Environment
Installing supporting tools (VS Code, Git, MongoDB)
Directory structure and first project initialisation
Each step includes command examples and diagrams for clear understanding.

1.2 System Prerequisites

Ensure your system meets the following minimum requirements:
Component
Requirement
Operating System
Windows 10+, macOS 12+, or Linux (Ubuntu 20.04+)
Python
Version 3.8 or higher
Package Manager
pip (comes with Python)
Editor
Visual Studio Code (recommended)
Version Control
Git
Database
MongoDB (via Djongo or pymongo integration)
Browser
Chrome / Firefox (for testing applications)

1.3 Development Environment Setup

Step 1: Verify Python Installation

Open your terminal (Command Prompt / PowerShell / Terminal) and check:
python --version
​
If Python is not installed, download and install it from:
https://www.python.org/downloads/
Ensure to check “Add Python to PATH” during installation.
To verify
pip
:
pip --version
​

Step 2: Install Virtual Environment

Virtual environments help isolate dependencies for each project.
pip install virtualenv or py -m pip install virualenv
​
Create a virtual environment named
venv
:
python -m venv venv
​
Activate it:
Windows
venv\Scripts\activate
​
Mac/Linux
source venv/bin/activate
​
Once activated, the terminal prompt will show
(venv)
before your command line.

Step 3: Install Django

Inside the activated virtual environment, run:
pip install django
​
Verify the installation:
django-admin --version
​

Step 4: Install MongoDB and Connector

MongoDB will serve as our NoSQL database. Download it from:
https://www.mongodb.com/try/download/community
After installation, verify:
mongo --version
​
To connect Django with MongoDB, install Djongo (or alternatively
pymongo
):
pip install djongo
​
This enables Django ORM to work seamlessly with MongoDB as a backend.

Step 5: Install Supporting Tools

Visual Studio Code (VS Code)
Download and install from https://code.visualstudio.com
Recommended extensions:
Python
Django
GitLens
Prettier
Git Installation
git --version
​
If not installed, download from https://git-scm.com/downloads

1.4 Verifying the Setup

Let’s verify everything by creating your first Django project.

Step 1: Create Project Directory

mkdir django-fullstack cd django-fullstack
​

Step 2: Start Django Project

django-admin startproject myproject cd myproject
​

Step 3: Run Development Server

python manage.py runserver
​
You should see an output like:
Starting development server at http://127.0.0.1:8000/
​
Open the URL in your browser — the Django welcome page confirms successful setup.

1.5 Django Project Directory Structure

After project creation, your directory structure will look like this:
myproject/ │ ├── manage.py ├── myproject/ │ ├── __init__.py │ ├── asgi.py │ ├── settings.py │ ├── urls.py │ └── wsgi.py └── venv/
​
Diagram: Django Project Structure Overview
+---------------------------------------------+ | myproject | |---------------------------------------------| | manage.py -> Command-line utility | | myproject/ -> Core configuration | | ├── settings.py -> Global settings | | ├── urls.py -> URL routing | | ├── wsgi.py -> Web server interface | | └── asgi.py -> Async server config | | venv/ -> Virtual environment | +---------------------------------------------+
​

1.6 Common Setup Issues

Issue
Possible Cause
Solution
django-admin not found
Django not installed in virtual environment
Activate environment and reinstall Django
Permission denied
Missing admin privileges
Run terminal as administrator
Server not starting
Port conflict or syntax error in settings
Change port:
python manage.py runserver 8080
ModuleNotFoundError: djongo
Djongo missing or incompatible version
Reinstall compatible version
pip install djongo==1.3.6
